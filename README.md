## 🚀 Install Backend

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan storage:link
php artisan migrate
php artisan serve
```

### 🧩 Install Frontend

```bash
npm install
npm run build
npm run dev
```

### 🧩 Push Folder

```bash
npm install
npm run build
npm run dev
```

### 🧩 Pull Folder

```bash
npm install
npm run build
npm run dev
```
